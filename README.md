# Stalker Strike — интерактивная карта

Мини-сайт для страйкбольной игры в стилистике «Сталкера». В основе — выбранная синяя карта, поверх которой размещены интерактивные локации и красные светящиеся отметки аномалий. География исходного изображения сохраняется.

Сайт использует обычные HTML, CSS и JavaScript. Ключи API, сторонние сервисы и установка зависимостей не нужны. Локальный запуск требует Node.js.

## Открыть локально

В папке проекта выполните:

```sh
node server.mjs
```

Откройте локальный адрес, который выведет сервер. Для остановки нажмите `Ctrl+C`.

## Изменить точки

Все названия, тексты и координаты находятся в `places.js`. `x` и `y` — положение в процентах ширины и высоты карты, отсчёт от левого верхнего угла. `type` принимает `location` или `anomaly`.

Расположение и названия точек демонстрационные: это заготовка вымышленного игрового сценария. Правила игры, баланс и свойства аномалий здесь не заданы. Изображение карты находится в `assets/`.

## Опубликовать на GitHub Pages

1. Загрузите содержимое этой папки в корень GitHub-репозитория с основной веткой `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. В разделе **Actions** запустите **Publish Stalker Strike map** либо отправьте следующий коммит в `main`.
4. После завершения задания `deploy` ссылка на сайт появится в результате развёртывания и в **Settings → Pages**.

Workflow `.github/workflows/pages.yml` публикует только файлы сайта и папку `assets/`. Локальный сервер, README и служебные файлы в сайт не входят. Все пути относительные, поэтому карта подходит и для адреса вида `https://USERNAME.github.io/REPOSITORY/`.

Настройка публикации описана в [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
